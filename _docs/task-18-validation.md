# Checklist in task details (#18)

PM's delegated 2026-10-13 policy: task and checklist drafts share explicit Save. Named Delete confirmation removes a draft item; only successful Save performs permanent deletion. Example: completed Packing has checked A/B; uncheck A then Cancel leaves saved Packing/A/B unchanged; Save atomically reopens Packing and unchecks only A. Confirm Delete B then Cancel keeps B; confirm then Save removes B and compacts order.

The real MainActivity row-to-sheet flow now loads ordered saved children alongside the task/list snapshot. Each child has stable draft identity and optional saved identity; duplicate text never selects another item. New entries append unchecked. Editable labels retain draft text until Save, which trims Unicode whitespace edges and rejects blank/invalid Unicode. Add validates before staging. A nonempty unadded input gives an actionable Add-or-clear Save error. No arbitrary length limit is introduced.

One outer Room transaction validates the current parent/list and saved checklist snapshot, updates ordinary fields, applies confirmed child deletions, edits/checks existing children by ID, and appends new children. Changed/missing children require reopening rather than overwriting concurrent edits. Repository operations retain child identities/check state/order and rollback all task/child writes together on error. The internal createDraft helper saves the final checked state atomically: an unchecked addition reopens a completed parent; a checked addition does not transiently reopen it. Text/deletion alone retain completion timestamps. Existing parent row completion uses the saved checklist gate and reports blocked completion; checking the last child does not automatically complete the parent. Occurrence checklist edits use existing per-occurrence override behavior. Parent/list cascades cannot be resurrected.

Configuration recreation retains child drafts and deletion confirmation in TaskDetailsModel. Dismissal clears all drafts; pending writes block editing/submission/dismissal through the existing #17 guard. Checklist fields, 48dp labeled checkbox/Delete rows, named confirmation and Add/Save/Cancel share the existing scrollable safe/IME sheet and polite validation announcement. Context focus return remains the #17 native-window handoff.
