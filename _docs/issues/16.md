## Goal

Provide reusable task rows and title-first quick entry with correct list defaults.

## Acceptance criteria

- [ ] A task row shows title, completion control/state, priority, scheduled date when present, and meaningful metadata; undated rows omit misleading dates.
- [ ] Completed-today rows remain visible with crossed-out titles, and priority has a readable cue beyond color alone.
- [ ] Quick entry saves a nonblank title using the approved default priority and the current custom list or Inbox when opened from a date view/Home.
- [ ] After saving, the new task appears immediately in the matching view without a restart, and the input is ready for another entry.
- [ ] Blank/whitespace titles are rejected without creating a record; long titles, keyboard visibility, cancellation, and failed saves have clear outcomes.
- [ ] Tapping the completion control changes completion independently of tapping a row to request details, with no double actions.
