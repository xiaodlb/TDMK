## Goal

Run idempotent recurring-task/reminder reconciliation in background work while retaining launch-time catch-up.

## Acceptance criteria

- [ ] An appropriate Android background-work request is registered uniquely and does not multiply after repeated app launches.
- [ ] A delayed worker catches up the agreed recurrence range and schedules eligible future reminders via existing logic.
- [ ] Repeated worker runs produce no duplicate occurrences/alarms, and completed/deleted/excluded occurrences remain respected.
- [ ] Application launch still reconciles when background work was delayed, disabled, or never executed.
- [ ] A worker failure/retry leaves persisted records valid and is safe to replay; no exact-time delivery promise is made for background jobs.
- [ ] Targeted results cover normal execution, delayed execution, replay, and failure/retry with no network/account requirement.

## Out of scope

- Recurrence algorithm is tracked in [#13](https://github.com/xiaodlb/TDMK/issues/13).
- Exact alarm delivery is tracked in [#28](https://github.com/xiaodlb/TDMK/issues/28).
- Reboot/clock-specific triggers is tracked in [#30](https://github.com/xiaodlb/TDMK/issues/30).

## Constraints

- Prerequisites: #13 and #30.
- Files/scope: Background-worker registration and integration under app plus WorkManager dependency/configuration if required and focused worker checks.
- Use Kotlin, Jetpack Compose, Material 3, and Room/SQLite as applicable. Version one works offline without accounts; optional sync planning remains [#40](https://github.com/xiaodlb/TDMK/issues/40). Do not add unrequested features.
- Follow [AGENTS.md](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/AGENTS.md), [scope](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/_docs/plan.md), and [process](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/_docs/process.md). Read _docs/behavior.md and _docs/data-model.md for agreed rules/contracts; required unresolved decisions block implementation. Read testing/design guides before relevant work when present and report missing guides.
