## Goal

Provide reproducible local build/install instructions and a reviewable debug APK with known limitations.

## Acceptance criteria

- [ ] README.md names Android Studio/JDK/SDK prerequisites and exact setup, whole-test, single-test, debug-build, and phone-install commands.
- [ ] Following the documented commands from the project root produces a passing required test report and a debug APK; record build commit and artifact location.
- [ ] The review build installs and opens on a named Android phone or emulator, and the record states observed behavior and known limitations without claiming unperformed checks.
- [ ] Release-signing/distribution guidance explains local secret handling and the steps needed for a future release; no private key, password, machine SDK path, or generated build directory is committed.
- [ ] The APK and validation record identify the reviewed commit and link the acceptance findings from #38, including any remaining blockers.

## Out of scope

- Initial scaffold creation is tracked in [#1](https://github.com/xiaodlb/TDMK/issues/1).
- Feature acceptance walkthrough is tracked in [#38](https://github.com/xiaodlb/TDMK/issues/38).
- Accessibility audit is tracked in [#37](https://github.com/xiaodlb/TDMK/issues/37).

## Constraints

- Prerequisites: #1 and the verified application/acceptance findings from #38.
- Files/scope: README.md, _docs/build-and-distribution.md, and an ignored debug APK/review artifact; change build configuration only to correct a documented packaging defect.
- Use Kotlin, Jetpack Compose, Material 3, and Room/SQLite as applicable. Version one works offline without accounts; optional sync planning remains [#40](https://github.com/xiaodlb/TDMK/issues/40). Do not add unrequested features.
- Follow [AGENTS.md](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/AGENTS.md), [scope](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/_docs/plan.md), and [process](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/_docs/process.md). Read _docs/behavior.md and _docs/data-model.md for agreed rules/contracts; required unresolved decisions block implementation. Read testing/design guides before relevant work when present and report missing guides.
- Do not publish to an app store, sign a production release, or commit signing secrets in this task; this milestone only prepares a review build and release instructions.
