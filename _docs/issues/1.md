## Goal

Establish a minimal Kotlin/Compose Android project that builds a debug APK and has one passing local unit test.

## Acceptance criteria

- [ ] The repository contains a Gradle wrapper, a single Android app module, pinned Kotlin/Compose/Material 3 dependencies, and ignore rules excluding SDK paths, build outputs, credentials, and signing keys.
- [ ] Installing and opening the debug APK on a supported Android phone or emulator shows an empty full-screen launch surface without a crash; record the device/API and result.
- [ ] The documented local-test command produces a report showing at least the one scaffold test passing with zero failures; the documented debug-build command produces app/build/outputs/apk/debug/app-debug.apk.
- [ ] README.md lists compatible JDK/SDK prerequisites, setup, full test/build commands, a single-test command, and phone installation steps that another engineer can follow.
- [ ] _docs/task-1-validation.md records actual test/build results and separates any unperformed phone verification from completed checks.

## Out of scope

- Room setup and storage is tracked in [#5](https://github.com/xiaodlb/TDMK/issues/5).
- Navigation and feature screens is tracked in [#14](https://github.com/xiaodlb/TDMK/issues/14).
- Release/review packaging beyond the initial debug build is tracked in [#39](https://github.com/xiaodlb/TDMK/issues/39).

## Constraints

- Prerequisites: None. Existing scaffold commits and validation are already on codex/task-1-android-setup; verify them rather than recreate them. Phone launch verification is still pending in the current record.
- Files/scope: Gradle/wrapper and ignore configuration, app launch source/resources, one local test, README.md, and _docs/task-1-validation.md.
- TDMK uses Kotlin, Jetpack Compose, Material 3, and Room/SQLite for an offline personal Android planner. No accounts or cloud sync in version one; deferred sync planning is [#40](https://github.com/xiaodlb/TDMK/issues/40).
- Read [AGENTS.md](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/AGENTS.md), [scope](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/_docs/plan.md), and [process](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/_docs/process.md). Read _docs/testing-guidelines.md before tests and _docs/design-system.md before UI changes when present; report missing guides. Read _docs/behavior.md and _docs/data-model.md when present and relevant. Do not invent unresolved product rules.
