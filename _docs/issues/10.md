## Goal

Produce deterministic task results for Today, Upcoming, Anytime, overdue, and custom lists with priority ordering.

## Acceptance criteria

- [ ] With a fixed local date, Today selects scheduledDate=today, overdue selects unfinished scheduledDate<today, Anytime selects scheduledDate=null, and list views select their stable list ID (including renamed Inbox). Date views span all lists; unrelated dates/lists and historical completions are excluded from applicable active results, and task records are not mutated by filtering.
- [ ] Tasks Upcoming selects tomorrow through today+7 local calendar days inclusive; Home upcoming selects tomorrow through the current week's Sunday inclusive, with Monday the first day. On Monday 2026-10-12, October 13/18/19 are in Tasks Upcoming but October 12/20 are not; Home stops October 18. On Sunday Home upcoming is empty while Tasks Upcoming continues into the next week.
- [ ] Every task result sorts High, Medium, Low, then createdAt ascending, then stable ID ascending for equal timestamps; updatedAt, scheduled date and completion time do not replace these tie-breakers. A shuffled fixture across lists/priorities, equal creation times and changed update times produces the same ordered IDs on repeated runs.
- [ ] Automated deterministic checks and a concise result report cover local 23:59/00:00, Sunday/Monday, month/year rollover, leap day and null dates, including both inclusive Upcoming endpoints and the immediately excluded dates. Explicit timezone/clock inputs change today's classification without rewriting date-only scheduled values; reminders never act as task time slots.
- [ ] A controllable clock/date source makes the same dataset repeatable, and the completion-eligibility boundary is explicit for #11 reuse: unfinished plus completionDate>=today remain eligible for their applicable date/list views; completionDate<today is excluded without a database move. Same-day completed tasks are not globally lost by feeding only the current unfinished-only repository query into filtering; overdue remains an unfinished-only classification. Tests cover completed-today, older completed and backward-clock future completion days under #4; #11 retains completion commands/history grouping and Home's retention of formerly overdue same-day completions.
