## Goal

Expose manual backup export and restore in Settings with clear progress, confirmation, and error states.

## Acceptance criteria

- [ ] Settings contains labeled export and restore actions explaining included data and the approved restore policy.
- [ ] Export opens the destination picker, reports completion only after the write succeeds, and shows readable failure/cancellation outcomes.
- [ ] Restore opens the source picker and shows any required confirmation before replacing or merging existing data.
- [ ] Canceling the picker or confirmation leaves data and reminders unchanged, and repeated taps do not start conflicting operations.
- [ ] Progress prevents unsafe duplicate actions; malformed/unsupported backup errors explain the problem without claiming a successful restore.
- [ ] Successful restore refreshes all affected tabs and appearance/settings and shows completion; the flow is usable in light/dark mode.

## Out of scope

- Serialization/export engine is tracked in [#32](https://github.com/xiaodlb/TDMK/issues/32).
- Validation/restore transaction is tracked in [#33](https://github.com/xiaodlb/TDMK/issues/33).
- Cloud sync settings is tracked in [#40](https://github.com/xiaodlb/TDMK/issues/40).
