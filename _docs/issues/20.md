## Goal

Display task date views and custom lists using scrollable tabs with correct quick-entry behavior.

## Acceptance criteria

- [ ] Tabs appear in order: Today, Upcoming, Anytime, Inbox, custom lists, then Manage lists; horizontal scrolling exposes tabs that do not fit.
- [ ] Selecting a tab displays the matching filtered/list result with High-to-Low priority ordering and the approved tie-breaker.
- [ ] Completing a visible task leaves it crossed out for today, while historical completions are absent from active results.
- [ ] Quick entry from a custom list uses that list; entry from date views uses Inbox, and the result appears in every matching view.
- [ ] The selected tab survives routine recreation where valid, and removal of a selected custom list chooses a valid fallback.
- [ ] Empty views provide a clear state without hiding navigation or task entry; a long list set and large text remain usable.

## Out of scope

- Manage lists interface is tracked in [#21](https://github.com/xiaodlb/TDMK/issues/21).
- Per-tab search is tracked in [#26](https://github.com/xiaodlb/TDMK/issues/26).
- Foreground date-boundary refresh is tracked in [#35](https://github.com/xiaodlb/TDMK/issues/35).
