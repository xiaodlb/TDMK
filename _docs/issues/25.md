## Goal

Provide a full-screen note editor with title editing, bold, headings, and bullet lists that round-trip through local storage.

## Acceptance criteria

- [ ] Selecting or creating a note from #24 opens the full-screen editor with the correct saved title/body and a clear return path.
- [ ] Bold, headings, and bullet lists can be applied/removed through visible controls; reopening preserves the displayed formatting.
- [ ] Save timing, empty title/body, back navigation, and interruption follow #3's approved policy; failed saves show an error without claiming success.
- [ ] Typing at the start/middle/end, replacing a selection, changing formatting at the cursor, Unicode, and multiline lists preserve the intended text and selection behavior.
- [ ] Returning to Notes/Home after a save updates cards/previews and ordering without serialized markup or an application restart.
- [ ] The chosen editor approach is documented as compatible with #4's versioned format; unsupported stored versions follow that contract without silent data loss.

## Out of scope

- Note persistence is tracked in [#9](https://github.com/xiaodlb/TDMK/issues/9).
- Note delete/undo actions is tracked in [#27](https://github.com/xiaodlb/TDMK/issues/27).
- Search is tracked in [#26](https://github.com/xiaodlb/TDMK/issues/26).
- Whole-app accessibility audit is tracked in [#37](https://github.com/xiaodlb/TDMK/issues/37).

## Constraints

- Prerequisites: #9 and #24; note save/title rules from #3 and format from #4.
- Files/scope: Full-screen editor, formatting adapters/state, grid return integration, and targeted checks under app; version catalog changes only if required by the documented compatible editor choice.
- Use Kotlin, Jetpack Compose, Material 3, and Room/SQLite as applicable. Version one works offline without accounts; optional sync planning remains [#40](https://github.com/xiaodlb/TDMK/issues/40). Do not add unrequested features.
- Follow [AGENTS.md](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/AGENTS.md), [scope](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/_docs/plan.md), and [process](https://github.com/xiaodlb/TDMK/blob/codex/task-1-android-setup/_docs/process.md). Read _docs/behavior.md and _docs/data-model.md for agreed rules/contracts; required unresolved decisions block implementation. Read testing/design guides before relevant work when present and report missing guides.
