## Goal

Provide a minimal four-tab navigation shell with a Settings route from Home.

## Acceptance criteria

- [ ] Home, Tasks, Notes, and Log appear as four labeled bottom-navigation destinations and each opens the correct placeholder screen.
- [ ] Home contains a visible Settings entry that opens Settings and returns through Android Back without unexpected app exit.
- [ ] The selected destination survives routine activity recreation, and repeat taps do not stack duplicate copies of the same screen.
- [ ] Android Back behavior from Settings and main destinations is documented and verified on a phone/emulator.
- [ ] Tab labels/focus targets are accessible, content does not overlap system bars, and large text does not hide navigation labels.

## Out of scope

- Persisted appearance choices is tracked in [#15](https://github.com/xiaodlb/TDMK/issues/15).
- Tasks screen content is tracked in [#20](https://github.com/xiaodlb/TDMK/issues/20).
- Home dashboard content is tracked in [#22](https://github.com/xiaodlb/TDMK/issues/22).
- Completion history content is tracked in [#23](https://github.com/xiaodlb/TDMK/issues/23).
- Notes grid content is tracked in [#24](https://github.com/xiaodlb/TDMK/issues/24).

- Prerequisites: #1.
- Files/scope: Compose navigation shell, placeholder destinations, Settings route, and minimal navigation checks under app/src; no domain storage or feature UI.

Read _docs/behavior.md and _docs/data-model.md for agreed rules/contracts; required unresolved decisions block implementation. Read testing/design guides before relevant work when present and report missing guides.
