## Goal

Show all overdue and today's tasks, then this week's upcoming tasks and recent notes on Home.

## Acceptance criteria

- [ ] Home is the initial destination and shows all overdue and today's tasks without truncating them to short previews.
- [ ] Upcoming excludes today's tasks and displays the remaining scheduled tasks through Sunday; on Sunday the section has no later-week tasks.
- [ ] Task sections use the agreed priority/tie-breaker ordering and keep applicable completed-today tasks crossed out while hiding historical completions.
- [ ] Recent notes use the count and ordering approved in #3 and display readable previews, without task-note linking.
- [ ] Task and note taps open the existing task sheet and full-screen note editor; completion and quick entry update the dashboard without restart.
- [ ] Empty sections, a long daily workload, large text, and Monday/Sunday/year boundaries have verified visible results.

## Out of scope

- Home search field is tracked in [#26](https://github.com/xiaodlb/TDMK/issues/26).
- Foreground date refresh mechanism is tracked in [#35](https://github.com/xiaodlb/TDMK/issues/35).
- Filtering algorithm is tracked in [#10](https://github.com/xiaodlb/TDMK/issues/10).
- Note-editor implementation is tracked in [#25](https://github.com/xiaodlb/TDMK/issues/25).
